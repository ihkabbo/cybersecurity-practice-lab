This repository documents my hands-on cybersecurity learning environment and practical exercises.

The lab is designed to help me develop practical knowledge of Linux systems, networking, and cybersecurity fundamentals using virtual machines.

- Kali Linux
- Ubuntu Server
- VMware Workstation
- Linux Command Line

- Develop foundational skills in ethical hacking and system administration.

## 🧪 Practical Activities

- Basic networking exercises.
- Exploring the Kali Linux environment.
